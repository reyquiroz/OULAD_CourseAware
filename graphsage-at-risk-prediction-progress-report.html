Executive Summary

Overview

This report summarises the completed experimental results comparing a heterogeneous GraphSAGE model against tabular baselines for predicting student at-risk status in the Open University Learning Analytics Dataset (OULAD). Experiments cover four prediction windows (weeks 2, 4, 6, 8), three evaluation protocols on OULAD, external validation on a Zenodo-hosted replication dataset, and a set of architectural ablations and variants.

Key finding: GraphSAGE variants with additional feature enrichment (temporal behavior, enrollment summaries, edge-aware message passing) consistently outperform the best tabular baseline (LightGBM 0.863) on the random-student split at week 8, reaching up to 0.888 AUROC. The MLP matched-protocol baseline (0.857) is competitive with LightGBM. Under stricter generalisation protocols (LCPO, future-presentation) the GNN advantage narrows. External validation on Zenodo reveals near-random performance, indicating the model has not yet learned features that transfer across institutional datasets.
Approach

Methodology

Graph Construction

The heterogeneous graph represents the learning environment with four node types — students, modules, assessments, and VLE resources — and four edge types: enrolled_in, submitted, interacted_with, and contains_assess / has_resource. A dual temporal guard ensures no future information leaks in: assessment features are only included when both the due date and submission date fall within the prediction window.

GNN Architecture

Two-layer heterogeneous GraphSAGE with mean aggregation. The prediction head operates on enrolled_in edge embeddings (concatenating student and module-presentation node representations), producing one logit per enrollment. Class imbalance is handled by weighted or unweighted cross-entropy loss. Six architectural variants are evaluated in addition to the base model.

Evaluation Protocols

  • Random-student split — 80/20 student split; 5 seeds (W8), 4 seeds (W2/4/6).
  • LCPO — 22 folds; each holds out one module × presentation; 5 model seeds per fold. Now evaluated across all four prediction windows.
  • Future-presentation — train on earlier presentations, test on the most recent (single run).
  • Zenodo external validation — zero-shot transfer to an independent institutional dataset.

Key Findings

Key Findings

1. GNN variants surpass the tabular ceiling on the random-student split

Four GNN variants (temporal features, enrollment summaries, edge-aware MP, enrollment-node) achieve 0.883–0.888 AUROC at week 8 — 2–3 points above LightGBM (0.863) and MLP (0.857). This is the first result in this project where a GNN model clearly beats the best tabular baseline. The base GNN (0.838) does not; the gain comes from architectural enrichment.

2. Temporal behavior features are the highest-value GNN enhancement

GraphSAGE + temporal behavior features achieves 0.888 AUROC (F1 0.811, Bal. Acc. 0.797) — the highest result across all models. This variant encodes time-ordered VLE interaction patterns rather than aggregate summaries, confirming that the trajectory of student engagement carries signal beyond what aggregate node features capture.

3. MLP nearly matches LightGBM across all protocols

The matched-protocol MLP (0.857 random-student, 0.829 LCPO at week 8) is within 0.006–0.006 of LightGBM across both splits and all prediction windows. This confirms the tabular feature engineering is the dominant contributor to performance, and that architecture choice among tabular models is secondary.

4. Assessment features are the dominant signal in all models

Removing assessment features from the GNN causes the largest single drop (−0.029 AUROC). The tabular ablation shows the same: assessment-only LightGBM (0.807) beats VLE-only (0.763) at week 8. Both GNN and tabular pipelines are most sensitive to assessment submission data.

5. GNN LCPO performance trails tabular at all prediction windows

Under LCPO the GNN (0.722–0.788) consistently trails LightGBM (0.752–0.835) and MLP (0.734–0.829) at every window. The GNN's random-student advantage (+0.025 at W8) disappears under leave-course-out evaluation, suggesting that while the graph structure adds value in-distribution, it encodes course-specific patterns that do not transfer cleanly to unseen module–presentation pairs.

6. Large course-level variation under LCPO (GGG outlier)

LCPO AUROC ranges from 0.668 (module GGG) to 0.849 (module FFF). The 21-point gap and GGG's consistently low performance indicate that prediction difficulty is strongly course-dependent. Module-conditioned prediction heads or course-specific calibration would be natural next steps.

7. Zero-shot Zenodo transfer fails

External validation yields AUROC ≈ 0.554 (random) and ≈ 0.499 (LCPO) — near random. The model has overfit to OULAD-specific feature distributions. Cross-institutional deployment would require domain adaptation or target-institution fine-tuning.

Next Steps

Recommended Next Steps

Immediate experiments (within current scope)

  • LCPO evaluation of GNN variants. All four high-performing variants (temporal, enrollment summaries, edge-aware MP, enrollment-node) have only been evaluated on the random-student split. Running them under LCPO would show whether the performance gains persist under stricter generalisation.
  • GNN ablations for weeks 2/4/6. Currently ablations cover week 8 only. Extending to earlier windows would show when each feature type becomes informative as the prediction window grows.
  • Matched-protocol LightGBM for weeks 2/4/6. Currently only week 8 has a matched-protocol result; multi-week values would complete the apples-to-apples comparison with GNN and MLP.

Model improvements

  • Course-conditioned prediction head. Address module GGG's persistent underperformance by conditioning the prediction head on module identity.
  • Combine top-performing variants. Temporal features + enrollment summaries + edge-aware MP have each been tested independently; combining them may push AUROC further.
  • Domain-adaptive fine-tuning for Zenodo. Pre-train on OULAD, fine-tune on a small labelled sample from the target dataset to address cross-institutional transfer failure.

Evaluation extensions

  • GNN future-presentation split. No pipeline support currently exists for this; implementing it would complete the three-protocol comparison for GNN variants.
  • Fairness / subgroup analysis. Disaggregate results by demographic features (gender, disability, IMD band) before any deployment consideration.
  • Calibration analysis. The Zenodo high-recall / low-precision pattern warrants probability calibration (Platt scaling or temperature scaling) for production use.
