Executive Summary

Overview

This report summarises the completed experimental results comparing a heterogeneous graph neural network (GraphSAGE) against tabular baselines for predicting student at-risk status in the Open University Learning Analytics Dataset (OULAD). Experiments cover four prediction windows (weeks 2, 4, 6, 8), three evaluation protocols on the original OULAD data, and an external validation on a Zenodo-hosted replication dataset.

Approach

Methodology

Graph Construction

The heterogeneous graph represents the learning environment as a set of node types — students, modules, assessments, and VLE resources — connected by four edge types: enrolled_in (student → module-presentation), submitted (student → assessment), interacted_with (student → VLE resource), and contains_assess / has_resource (module → assessment / resource). Temporal leakage is prevented by a dual guard: assessment features are included only when both the due date and submission date fall within the prediction window.

GNN Architecture

Two-layer heterogeneous GraphSAGE with mean aggregation. Node features: demographic and registration metadata for students; structural and VLE-interaction summaries for modules. Edge features on submitted edges encode assessment score and days-before-due. The prediction head operates on enrolled_in edge embeddings (concatenating student and module-presentation node representations), producing one logit per enrollment. Class imbalance is handled either by weighted cross-entropy loss or left unweighted (both variants are evaluated).

Evaluation Protocols

  • Random-student split — 80/20 split on students; 5 random seeds (week 8), 4 seeds (weeks 2/4/6).
  • Leave-Course-Presentation-Out (LCPO) — 22 folds, each holding out one module × presentation pair; 5 model seeds per fold. Tests course-level generalisation.
  • Future-presentation — train on all earlier presentations, test on the most recent. Single run. Tests temporal generalisation.
  • Zenodo external validation — full GNN trained on OULAD, evaluated on an independent Zenodo-hosted dataset with the same schema but different institutional context.

Prediction Windows

Features are truncated at days 14, 28, 42, and 56 (weeks 2, 4, 6, 8 respectively). Only data observable before the cutoff date is included; no future information leaks in.

Key Findings

Key Findings

1. Tabular models are strong baselines

LightGBM with all features achieves 0.863 AUROC at week 8 on the random-student split, establishing a strong ceiling for OULAD in-distribution performance. The gradient boosting models (XGBoost and LightGBM) are within 0.001 of each other and outperform the GNN by 2.4–2.5 AUROC points in this setting.

2. GNN is competitive but does not exceed tabular performance on OULAD

GraphSAGE reaches 0.838 AUROC (random-student, W8) — 2.5 points below LightGBM. The GNN performs on par with LightGBM at the earliest prediction window (week 2: 0.766 vs. 0.769), suggesting that the graph structure adds proportionally more value when fewer temporal observations are available.

3. Assessment data is the dominant signal in both pipelines

Removing assessment features from the GNN causes the largest single drop (−0.029 AUROC). The same pattern holds in the tabular ablation: assessment-only LightGBM (0.807) beats VLE-only LightGBM (0.763) at week 8. This is consistent with the fact that submission patterns and scores are the most direct indicators of academic difficulty by week 8.

4. VLE engagement adds independent value

Removing VLE features from the GNN reduces AUROC by 0.014 (next largest after assessment). The tabular VLE + assessment model (0.838) substantially outperforms either modality alone, confirming that engagement and performance signals are complementary.

5. Interaction-weight edge attributes improve GNN performance

Adding raw interaction-weight edge attributes on VLE edges improves AUROC to 0.846 (+0.008 over base). This is the highest GNN result reported and suggests that the cardinality / frequency of individual VLE interactions contains signal not captured by the aggregate node features currently used.

6. Large course-level variation under LCPO

LCPO AUROC ranges from 0.660 (module GGG) to 0.874 (module FFF) for the GNN. Module GGG is a consistent outlier. This 21-point range suggests that at-risk prediction difficulty is highly course-dependent and that the model learns module-specific patterns not fully transferable to unseen courses.

7. External validation shows no cross-institutional transfer

Zero-shot evaluation on the Zenodo dataset yields AUROC ≈ 0.554 (random) and ≈ 0.499 (LCPO), both near random. The model has overfit to OULAD-specific feature distributions. Cross-institutional deployment would require domain adaptation or retraining with target-institution data.

Next Steps

Recommended Next Steps

Immediate (within current experimental scope)

  • Run GNN LCPO for weeks 2/4/6. Currently only week 8 LCPO results exist. Multi-week LCPO would complete the generalisation picture across temporal windows.
  • Ablate interaction-weight attributes under LCPO. The with_iw_attrs variant (0.846 random-student) has not yet been evaluated under LCPO — this would confirm whether the gain persists under stricter generalisation.
  • Run matched-protocol LightGBM for weeks 2/4/6. Currently only week 8 has a matched-protocol result (0.856); multi-week parity testing would allow a fair apples-to-apples comparison.

Model improvements

  • Course-conditioned prediction head. Separate prediction weights per module could address the GGG generalisation gap without sacrificing performance on well-represented modules.
  • Attention-based aggregation. Replace mean-aggregation GraphSAGE with GAT to learn which neighbour types are most informative per enrollment.
  • Temporal message passing. Encode time-ordered VLE interactions as sequences (e.g., via GRU on the interaction graph) rather than aggregate node features, to better capture behavioural trajectory.
  • Domain-adaptive fine-tuning for Zenodo. Pre-train on OULAD, fine-tune on a small labelled sample from the target dataset to address the cross-institutional transfer failure.

Evaluation extensions

  • GNN future-presentation split. No pipeline support currently exists for this; implementing it would round out the three-protocol comparison.
  • Calibration analysis. High recall / low precision on Zenodo suggests probability miscalibration; Platt scaling or temperature scaling post-hoc could improve actionability of risk scores.
  • Fairness / subgroup analysis. Disaggregate results by demographic features (gender, disability, IMD band) to assess whether the model performs equitably across student subgroups before any deployment consideration.
