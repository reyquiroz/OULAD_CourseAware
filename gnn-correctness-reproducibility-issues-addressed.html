Training graph included held-out information
Message-passing separation · src/gnn_model.py · src/run_gnn_experiment.py
FIXED
Problem

The full heterogeneous graph — including validation and test student nodes, their enrolled_in edges, and their submission/interaction edges — was passed through the GNN during every training forward pass. Only the loss was masked to training rows, so held-out students influenced learned representations via message-passing.

Fix

New build_train_subgraph(data, train_mask) returns a copy of the graph with enrolled_in, submitted, and interacted_with edges filtered to training students only. The training loop uses this subgraph for loss computation; the full graph is used only for validation and test inference.

  • Added build_train_subgraph() in gnn_model.py — filters 3 edge types to training student indices; preserves all node features and structural edges
  • Refactored run_training_loop(model, train_subgraph, full_data, val_mask, …) — forward pass uses subgraph; validation uses full graph
  • Updated both run_random_split_experiment() and run_lcpo_experiment() to build and pass the subgraph
2
Normalisation computed on the full graph
Feature leakage · src/gnn_model.py
FIXED
Problem

_normalize_numeric_features() computed mean and standard deviation over all 32,593 enrollments before any split was applied. Normalisation statistics therefore incorporated validation and test data, leaking future information into training.

Fix

_normalize_numeric_features(data, train_edge_mask=None) now derives statistics from training rows only when a mask is provided. The computed parameters are then applied to all rows. Structural nodes (course_presentation, assessment, VLE resource) are normalised globally — documented in code. Callers pass skip_normalize=True to GraphDataLoader and normalise after building the split mask.

  • enrolled_in edge attrs: stats from edge_attr[train_edge_mask] only
  • submitted / interacted_with edges: stats from training-student rows only
  • Student node features: stats from training-student node subset
  • Added GraphDataLoader(skip_normalize=True) flag for deferred normalisation
3
Student representation mixed cross-course information
Representation leakage · EnrollmentGNN architecture · src/gnn_model.py
FIXED
Problem

Three pyg_scatter calls aggregated edge attributes from all of a student's enrollments — across all courses — into a single shared student-node representation between conv layers. A student enrolled in multiple courses received a representation that mixed course-specific and potentially future-course information.

Fix

The scatter injections are removed. enrolled_in edge attributes are now projected per-edge via ei_attr_proj and concatenated with the student and course-presentation embeddings in the edge prediction head: [h_student ‖ h_course ‖ proj(ei_attr)] → Linear → logit. Each enrollment prediction is independent.

  • Removed enrollment_attr_proj, submitted_attr_proj, interacted_with_attr_proj modules
  • Added ei_attr_proj = nn.Linear(n_enrolled_in_attr, hidden_dim)
  • Edge head input dimension: hidden_dim × 3 (student + course + ei_attr projection)
  • submitted / interacted_with topology still present for message-passing
4
LightGBM comparison not fully matched
Feature parity · threshold alignment · src/compare_gnn_lgbm.py
FIXED
Problem

LightGBM received 7 features while the GNN used richer enrollment-scoped inputs. LightGBM trained on the combined train+val set, used no val set for early stopping, and applied a fixed 0.5 decision threshold — unlike the GNN's F1-maximising threshold on the val set.

Fix

LightGBM now reads age_band (one-hot) and studied_credits from the enrolled_in artifact parquet, matching the GNN's edge attributes. It trains on the train split only and uses the same val-set select_threshold() procedure as the GNN. LCPO uses a 10% val draw per fold with the same RNG protocol.

  • New build_enrolled_in_features(week) reads artifact parquet for age_band, studied_credits
  • run_lgbm_random_split(): trains on train-only, tunes threshold on val via select_threshold()
  • run_lgbm_lcpo(): 10% val draw per fold matching GNN LCPO protocol
  • _compute_metrics(threshold=) kwarg for tuned threshold propagation
5
LCPO used one model seed per fold with conflated RNGs
Variance estimation · reproducibility · src/run_gnn_experiment.py
FIXED
Problem

Each LCPO fold trained exactly one model using a seed derived from SEED + fold_idx. The same value controlled both the val-student sampling RNG and the model weight initialisation, so these two sources of randomness could not be analysed independently.

Fix

run_lcpo_experiment(model_seeds=[42, 123, 7, 17, 99]) now runs 5 model seeds per fold. The val-student sampling RNG is keyed on fold_idx alone — so the same validation set is used across all 5 seeds within a fold. Results include per-seed rows and fold-level mean ± std.

  • Inner for mseed in model_seeds loop per fold; torch.manual_seed(mseed) before each model init
  • Val RNG: np.random.default_rng(fold_idx) — decoupled from model seed
  • lcpo_results.csv gains model_seed column (one row per fold × seed)
  • lcpo_summary.csv reports {metric}_mean and {metric}_std per fold
  • --model-seeds CLI argument added
6
Result files inconsistent and reproduction script unsafe
Reproducibility · src/run_gnn_experiment.py · scripts/reproduce_all.sh
FIXED
Problem

Training curve filenames omitted week and seed, so multi-week or multi-seed runs silently overwrote earlier files. Result CSVs were overwritten on every run. The reproduction script offered no guard against missing graph artifacts, causing cryptic failures mid-run.

Fix

Training curves are now namespaced per week, seed, and loss-weighting. Result CSVs use an append-safe pattern (read–concat–deduplicate–write). The reproduction script checks for required parquet artifacts before starting experiments and aborts with instructions if they are absent.

  • Curve filename: training_curves_random_student_week{N}_seed{S}_{weighting}.npz
  • LCPO curves: training_curves_lcpo_fold{F}_seed{S}.npz
  • _append_or_create_csv(df, path, dedup_keys) helper — safe re-runs
  • Preflight check in reproduce_all.sh aborts if week08_enrollments.parquet missing
7
Result files and manuscript statements inconsistent
Single source of truth · src/generate_report_figures.py · src/verify_results.py
FIXED
Problem

Multiple CSV files (random_student_results.csv, lcpo_results.csv, comparison_results.csv) could diverge if regenerated independently. Figure and table generation read from multiple sources with no consistency guarantee. Course-level win count was reported as 19/22 while the CSV showed 18/22.

Fix

generate_report_figures.py now reads exclusively from comparison_results.csv. A new verify_results.py script recomputes every aggregate from that file and diffs it against results/graph/tables/, exiting non-zero on any discrepancy > 10−4. compare_gnn_lgbm.py gains a --from-csv flag to rebuild the comparison file without re-running the GNN.

  • generate_report_figures.py: single read from comparison_results.csv; hard error if missing
  • New src/verify_results.py: recomputes means, stds, win counts and diffs against tables/
  • compare_gnn_lgbm.py --from-csv: rebuilds combined CSV from existing GNN results + fresh LightGBM

Tests did not cover the most important risks
Test coverage · tests/ (6 new files)
FIXED
Problem

The 29 existing tests covered split correctness and filter boundaries but left critical risks untested: training-only normalisation, held-out graph isolation, cross-course aggregation invariance, label alignment after subgraph filtering, full-model training convergence, and LCPO fallback val-sampling behaviour.

Fix

13 new tests across 6 files cover all identified risk areas using in-memory toy graphs only — no parquet files required, total runtime < 6 s. The fallback val-sampling logic was extracted to _sample_lcpo_val() to make it unit-testable.

  • test_normalization.py — train-mask stats differ from global; zero-mean on training slice; student subset
  • test_subgraph.py — held-out students absent from subgraph; y length; no in-place mutation
  • test_no_cross_course.py — perturbing held-out edge attrs leaves training logits unchanged
  • test_label_alignment.py — label order preserved before and after subgraph filtering
  • test_training_smoke.py — loss decreases over 5 epochs; logit count matches training edges
  • test_validation_fallback.py — fallback triggers when val positives < 20; train/val disjoint
